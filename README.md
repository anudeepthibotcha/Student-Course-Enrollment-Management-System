The **Student Course Enrollment Management System** is a MySQL-based database project developed to manage student information, 
course details, and course enrollment records in an educational institution. The system uses three main tables: 
`students` to store student details, `courses` to store course information such as name, category, instructor, credits, and 
fee, and `enrollments` to maintain the relationship between students and courses along with enrollment dates, status, and marks. 
The project demonstrates practical SQL concepts such as table creation, primary and foreign keys, data insertion, 
joins, filtering, aggregate functions, `GROUP BY`, `HAVING`, subqueries, and conditional queries to generate reports 
like student enrollment details, course-wise student counts, average and highest marks, and student performance.
